# Contributing

This is a finished hobby project and it is **not accepting pull requests or feature requests**. Please fork it
and make it your own: the licence (see `docs/licenses.md`) lets you. Bug reports are welcome as issues, but there is
no promise of a reply or a fix.

If you do fork it and add content, keep three rules: no copyrighted or copyright-adjacent music, lyrics or audio;
no real person's, artist's, band's or show's name in a generation prompt; no secrets in the repo (see the README's
API keys section).
